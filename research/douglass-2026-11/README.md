# 弗雷德里克·道格拉斯：研究检查点

核心问题：一个被禁止决定自己去处与工资的人，怎样逐步取得公开讲话、印刷、参军动员以及担任公职的权力；每种新权限仍把谁留在门外。

时间及证据骨架：塔尔博特县（约1818，贝莉家系与安东尼、劳埃德两层管理）、巴尔的摩（奥尔德夫妇，费尔斯角）、科维与弗里兰（租借、反抗和集体出逃未遂）、1838北行（安娜·默里、戴维·拉格尔斯、约翰逊夫妇）、1841–47（加里森、巡回演讲、三版自述中有意不公开的事项、英爱苏访问、理查森一家和文契）、1847–60（罗切斯特报馆、马丁·德莱尼、格里菲思与杰里特·史密斯；女权与宪法、布朗）、1861–65（征兵、两个儿子、林肯）、1865–77（投票、全国公约、报业、储蓄银行、纪念演说）、1877–95（华盛顿公职、雪松山、海伦·皮茨、海地使职、反私刑与去世）。预计正文前半约9千，战争及后半约9千五。

已通读/摘读：1845《自述》使用 ibiblio 据初版分页的全文，特别第一、二、五至十一章及附录；1881《生平与时代》Gutenberg 可读正文，尤其第二部出逃、英伦和赎买。交叉：美国国会图书馆档案及年表，国家公园管理局年表与宅邸文献，女儿罗塞塔1900讲稿（1923刊本），西北大学交易档案目录，1847《北极星》所印法律文书，David W. Blight 对家庭档案与自传写法的访谈。科维年份、转让时点及美元折合出现版本差异，按具体文书动作分别说明。

新增一手材料：1847年创刊号（社论和试刊订费）、1852年独立日讲词、1860年格拉斯哥宪法讲词、1869年平等权利协会会议及同年波士顿演说、1881年布朗讲词及1881年自传不同章、1892增订本银行章、1876年揭幕讲词与五天后报纸来信、1891年发给布莱恩的帆船交涉公文、1893海地讲稿及展馆致辞、1892年印在威尔斯《南方恐怖》前的信和1894年反私刑印本，均按具体事件配注。现代研究使用 Blight 的访谈和国家公园管理局遗址长篇研究报告第二章；全文不可得之专著不假作已读。图片来自公版的题名页、照片、报纸、征募印本、石印画共六幅，均实际查看；具体年代、版本与授权在图注。

事实审读：不把第三本自传的水手证照和安娜家属回忆混为一个来源；核对银行上任捐资和清算余额、费城征募告示和马萨诸塞团别、军方行程令和实际履职、八月会晤和后来的自传回忆、海地军港与商船谈判。按发函原件改订商船公文为二月九日；纪念碑揭幕与刊发来信分别定位。关于科维的具体纪年，初版、后来本与现代年表有出入，正文不用推定的日月；雪松山采用遗址报告所述购置年代。

文字审读：开篇先置叙述选择，再回到马里兰。减去对报馆、白宫礼仪和港口交涉的抽象转喻；统一安娜、奥尔德、雪松山译名，按首次出现次序重排尾注。把家庭及其资金放入各次迁居中，公职及反私刑活动各以实际工作的材料收束。
