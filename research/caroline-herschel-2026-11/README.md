# 卡罗琳·赫歇尔：出版研究记录

本篇于2026-11-21草稿分支开始保存，11月22日继续补写。三篇十月旧文已完成，本次没有覆盖其文章、统计或调度。当前发表状态与精确汉字、图、注释数以progress.json为准；完成构建和部署前不标completed。

核心问题：卡罗琳怎样在歌唱、家庭协作、独立搜寻和编目之间取得可用的时间、收入、仪器及知识。正文依人生进程展开，后半生以1798原书、1799—1801迁居日记、1824—1825编目与财产通信、1830—1848继续转送材料及回忆写作为主。

## 证据与争议

- 原书将遗漏星按信息完整程度分组，正文写方法与边界，不从不同版本的860/560/561中任选数字，更不称为新发现的恒星。
- 彗星八次历史记录与独占优先权分开；1793年梅西耶先见，1797年同时发现。
- 1788婚后住宅地内小屋，1797秋迁寓所；私人日记缺失不等于观测簿消失。
- 1787年薪与工程款、1824追记欠薪及1803补贴分别交代。
- 1838年仪器交豪斯曼，纠正1876编者送返英国说法。
- 家系、童年和音乐经历多为晚年回忆；1844铁路宴会消息为她转述，不写成现场。
- 女性学会身份限1835荣誉会员，1828用学会当时名称。

关系与地点：伊萨克/安娜·伊尔泽、雅各布/威廉/亚历山大/迪特里希，玛丽·皮特、约翰及其妻玛格丽特；奥贝尔、布拉格登、马斯基林一家、班克斯、拉朗德、皮戈特、高斯、哈丁、布卢门巴赫、贝利、萨默维尔、豪斯曼、贝克多夫和克尼平。主要地点汉诺威—巴斯—达切特—斯劳与附近寓所—汉诺威；伦敦和格林尼治为通信、付印和访问节点，好望角通过侄子来信出现。
