# 戈雅传记：材料与续写记录

核心问题：一个靠委托和薪俸生活的画家，怎样在不同的制度、媒介与观众之间安排自己的工作？从一八〇三年的铜版交割切入，按人生顺序追查同一个人的收入、署名、生产关系与作品去向。

## 审读与版面

事实轮以书信和机构文件逐段核对了年金、病状、战争委托、人物关系和图版。将哈维尔年金停付移到1806年，补上当时的旅游证明争议；按1781年9月22日信修正圣伯尔纳定画题和画幅约束；用1814年3月公函区分申请、经费和绘制；区分1824年请假和1826年带薪退休；按出生年份校正法国死亡登记年龄。保留莱奥卡迪娅作为当事人的说法，与领事记录分开。文字轮重排年金段落和赴法后的延期，删改关于出资、买家与画面证词的过度判断，并按首次出现重排注释。插图以原藏品和历史照片作对照，逐一确认图像来源和权利声明，保留完整图版比例。部分机构对自动请求返回403或418；实际采用的书信同时核对可访问的《Diplomatario》扫描本，曾读到的馆藏页有助查证原件和权利，其余可访问链接列在注释中。
